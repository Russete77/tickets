RUNNING THE TESTS:
==================
Development:
  npm run test:e2e              Run all tests headless
  npm run test:e2e:ui          Run with interactive UI (can see browser)
  npm run test:e2e:debug       Run in debug mode with inspector

Specific Tests:
  npx playwright test e2e/home.spec.ts        Run only homepage tests
  npx playwright test -g "login"               Run tests matching pattern
  npx playwright test --project=chromium       Run only in Chrome

CI/CD:
  CI=true npm run test:e2e     Run in CI mode (1 worker, 2 retries)

View Results:
  npx playwright show-report   View HTML test report
  npx playwright show-trace    View execution trace (with screenshots/videos)
