USAGE
=====

Setup (First Time):
  1. Set database URL:
     export TEST_DATABASE_URL="postgresql://user:pass@localhost:5432/test"
  
  2. Apply migrations:
     npm run db:migrate

Running Tests:
  npm run test:integration              # Run all tests once
  npm run test:integration:watch        # Watch mode
  npm run test:integration -- auth      # Specific file
  npm run test:integration -- --grep "register"  # Pattern match

ARCHITECTURE
============

Why Serial Execution?
  - Prevents database lock contention
  - Avoids test interference
  - Trade-off: ~2 seconds for full suite

Why Real Database?
  - Catch actual constraints
  - Test real implementation
  - Complement unit tests

Why Supertest?
  - Tests Express directly
  - No server startup needed
  - Standard for Node.js

TEST STRUCTURE
==============

Each test file follows this pattern:

1. Import helpers and setup
2. beforeAll() - Create client/database
3. afterEach() - Cleanup test data
4. afterAll() - Close connections
5. describe blocks for organization
6. it() blocks for test cases
   - Arrange: Set up test data
   - Act: Make HTTP request
   - Assert: Verify response and side effects
